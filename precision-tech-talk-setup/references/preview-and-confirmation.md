# 效果图与最终确认

## 生成对比方案

按用户的风格方向制作 2–3 版明显不同、但都符合其约束的效果图。每版按目标画幅精确像素制作，至少包含：

1. 钩子帧：真人/主视觉 + 一句大字 + 关键词强调。
2. 数据或网页证据帧：观众能读清关键数字和来源。
3. 流程/列表帧：展示错峰弹出、焦点与非焦点透明度。
4. 字幕帧：真实字号的单语或双语字幕与局部黑底。

HTML 顶部记录每版参数：背景、主色、辅助色、文字色、字体栈、字号、圆角、描边、发光、遮罩透明度和动画节奏。可同时输出 PNG，方便用户直接比较。

## 迭代方式

给每版一句清晰定位，让用户选择整版或混搭元素。用户提出修改时，只改变被点名的参数并重新输出，不擅自改变其他已确认决定。

用户没有明确说“就这版”“确认”之前，不进入最终工程生成。

## 最终确认单

选版后汇总：

- 平台、画幅、内容形态
- 字幕语言、字号、位置、背景和关键词规则
- 背景、配色、字体、圆角、描边、发光与滤镜
- 动效密度、入场顺序、退场和 B-roll 规则
- 网页证据与联网授权
- BGM、音效和响度偏好
- Logo、栏目名、片尾与禁用项
- 模板名称、输出目录和交付内容

明确询问“确认后开始生成模板；要改哪一条现在说”。只有得到确认才写最终产物。
