# 每期素材放置区

- `master.mp4`：已经完成气口/卡壳剪辑且音画同步的口播主视频，必须保留人声轨。
- `video.srt`：与 `master.mp4` 对齐的中文字幕。
- `evidence/`：官方网页、报告页、图表和产品素材。
- `broll/`：已统一为 1920×1080、30fps 的全屏外部动画或实拍素材，由 `src/broll-plan.ts` 引用。
- `clips/`：非全屏的补充 B-roll 或录屏。
- `logo.png` / `avatar.png`：可选品牌资产。

不要把人声音频拆成独立时间线再单独裁剪。响度处理不能改变声音相对画面的时间。
