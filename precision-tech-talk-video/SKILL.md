# Precision Tech Talk · 视频成片

目标是复用一套稳定的“克制精密”视觉语言，同时让每期信息图由当期文案决定。不要把上期的品牌、数据、网页或时间点复制到新视频。

## 开始前

1. 识别用户提供的口播视频、SRT/逐字稿、已有配图和期望版本名。
2. 若是原始视频，需要剪气口、卡壳或停顿，先生成一个音画同步的 clean master；删除区间必须同时作用于视频与原音频，禁止分别剪切。若用户已提供剪好的无字幕视频，优先直接使用。
3. 若目标目录是新项目，用 `scripts/new_project.py` 从 `assets/starter/` 创建。目标已存在时脚本会拒绝覆盖。
4. 阅读 [视觉系统](references/visual-system.md)。分析字幕和规划动效时再读 [语义动效](references/semantic-motion.md)。需要插入外部动画/实拍 B-roll 时读 [外部动画与转场连续性](references/external-broll-and-continuity.md)。发现爆音、底噪或局部修复后音色不一致时读 [音频修复与统一母带](references/audio-repair-and-mastering.md)。准备渲染时读 [制作与验收](references/workflow-and-qa.md)。

## 必须先做语义时间线

以真实 SRT 为时间真源，把文案拆为“观点、因果、数字、对比、流程、时间线、证据、建议、总结”等语义单元。为每个单元记录：开始/结束、口播原句、信息目的、画面类型、证据来源、弹出顺序和退出时间。

动效必须在对应词句说到时才出现，并在语义结束后退出。一个视觉组件如果不能帮助理解、验证或记忆当前内容，就不要放。相邻段落不得因为复用组件而继续展示上一段信息。

对于外部动画，再为每个候选槽位记录：它替代哪一层画面、有效动作的入点/出点、是否需要裁头、目标时长、变速倍率、与底层信息动效的互斥区间。动画长度服从口播语义，不反过来拉长或改写口播。

## 视觉与字幕不变量

- 1920×1080、30fps；暗色科技滤镜、紫青主色、低强度发光。
- 真人主体优先，信息覆盖层放在人物空侧；只在信息密集时局部压暗，不常驻全屏黑膜。
- 中文主字幕 + 英文副字幕，仅有字幕时显示局部半透明黑底；不得常驻黑条。
- 元素按眉题、主体、关键数字/结论、解释项、来源依次错峰进入；入场后保持稳定，只保留计数、画线、慢滚动等有意义的运动。
- 真实数据优先使用官方报告、公司投资者关系页、监管文件或一手产品页。网页截图必须裁到观众能读清核心数字，并用放大框、高亮或重构数据卡说明，不能只贴一张缩小到看不清的整页。
- 事实和技术用蓝/青，涨价或注意用黄，风险/否定才用红；同一场景最多一个高饱和主色。

## 实施规则

- 复用 starter 中的 `EditorialKit` 组件；每期新建 `SemanticOverlays.tsx` 和语义计划，不把具体选题写回通用组件。
- 所有运动由 Remotion 帧、`interpolate()` 或 `spring()` 驱动；不使用 CSS transition/animation，也不使用随机值。
- 口播主视频保留自身音轨，所有裁剪统一作用于同一音视频时间线。BGM 与音效是附加轨，不得替代或漂移人声。
- 外部 B-roll 默认静音，必须位于真人和信息层之上、字幕之下。同一语义已有全屏 B-roll 时，关闭底层重复信息动效，避免淡出阶段露出仍在运动的组件形成闪帧。
- 真人底片与 B-roll 色调差异明显时，先把真人底片做轻度冷暗统一，再以约 8–12 帧叠化连接；不得用单帧闪白、硬切或全片重度滤镜掩盖不匹配。
- 音频修复先确认噪声来自原片、外部素材还是混音。局部修复造成音色边界时，回到未做局部处理的干净版本，对整条人声使用同一处理链；优先保留自然音色，不为追求“广播感”强行压缩。
- 网络资料必须记录直达来源和对应论断；无法核实的内容不做成“官方数据”样式。
- 用户没要求整体换风格时，不重新发明配色、字幕或动效节奏。

## 交付门槛

先渲染钩子、一个数据段、一个流程/建议段、片尾以及所有场景边界附近关键帧；逐张检查内容匹配、可读性、遮挡、字幕黑底和退场。外部 B-roll 还要检查每个入点、稳定帧、出点以及出点后 0.3–0.5 秒，确认无重复底层动效、黑帧、标识残留或突变。再做短片段预览，确认后才全片渲染。

最终至少交付可编辑工程、MP4、来源清单、语义时间线和 B-roll 槽位表；发生音频修复时另附处理区间与母带参数。报告分辨率、fps、编解码、时长、文件大小、响度与真峰值；保留上一版本，不静默覆盖。

## 用户最简输入

用户以后只需说：

> 使用 `$precision-tech-talk-video`，把我上传的科技口播做成与上次一致的暗色紫青科技风成片。视频在【路径】，SRT/文案在【路径】，本期主题是【主题】。请先按语义规划动效和证据画面，给我关键帧确认后再渲染。
