# 默认视觉系统：克制精密科技口播

只有项目中不存在用户确认的 `STYLE-PROFILE.md` 或 `style-profile.json` 时才采用本文件。存在风格档案时，以档案参数为准，不得用本文件的紫青默认值覆盖用户选择。

## 固定基线

- 画幅：1920×1080，30fps；左右安全区 80–100px，字幕底部约 52px，平台裁切风险较高时上移。
- 颜色：背景 `#070914`，主色 `#7C5CFF`，辅助色 `#28D7FF`，主文字 `#F7F8FF`，次文字 `#D7DCF4`。
- 面板：`rgba(5,13,29,.78–.88)`，1px 低透明青/紫描边，16–24px 圆角。
- 字体：中文优先思源黑体/微软雅黑；数字与英文使用粗体几何无衬线。标题 30–58px，主数字 64–110px，中文字幕约 43px，英文字幕约 27px。

## 真人底片与滤镜

保持肤色自然、背景略冷。推荐把视觉处理做成可关闭的覆盖层：

- 全局暗色蒙版 0.08–0.18。
- 信息所在一侧使用黑色渐变 0.28–0.52，人物脸部和手势区域尽量透明。
- 暗角只需帮助聚焦，不应让边缘细节全部消失。
- 紫青环境光低强度使用；不做大面积霓虹和持续闪烁。

## 字幕

- 中文在上、英文在下，居中对齐。
- 背景只包住当句字幕，建议 `rgba(0,0,0,.58)`；无字幕时整个字幕容器不存在。
- 中文 43px/800，英文 27px/500，行距分别约 1.12 与 1.18。
- 背景可不设圆角以保持纪录片感，或使用不超过 8px 的轻圆角；同一项目保持一致。
- 翻译要求意译清晰、长度适中、与中文逐条同索引。专有名词在全片保持统一。

## 元素层级与透明度

1. 眉题：蓝色竖线 + 英文大写标题 + 中文副题。
2. 主证据：真实网页、人物、产品图、时间轴或核心模型。
3. 解释层：标签、箭头、对比条、节点。
4. 来源层：来源、日期、页码。

推荐透明度：主证据 .92–1；次要说明 .68–.82；来源 .48–.68；已讲完节点 .3–.45；未讲到节点 0–.25。

## 动效节奏

30fps 下的通用顺序：0f 眉题，+3f 中文副题，+7f 主体，+11f 主数字/结论，随后每项间隔 3–5f，来源最后进入。单组约 0.9–1.1 秒完成。

起始状态以 `opacity:0`、10–24px 位移、`scale:.96–.98` 为主。可用 `spring({damping:18, stiffness:170, mass:.75})`，过冲不要超过约 1.02。退场使用 6–10 帧淡出或少量反向位移。

## 镜头密度

- 每 5–10 秒至少发生一次有意义的信息结构变化。
- 每 25–40 秒可安排一次更强的全屏 B-roll 或章节重置。
- 同一时刻只保留一个主视觉；信息多时分阶段替换，而不是全部堆在画面上。
